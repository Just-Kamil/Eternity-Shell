lists all the files in the current or specified directory

Usage:

    dir [OPTION] [PATH]

this command is able to use any flags that the "ls" command supports, for more detail on possible options please look up the man page for "ls".
Which can also be found here: https://man7.org/linux/man-pages/man1/ls.1.html

by default it uses the -la tag, and lists the current working directory.
